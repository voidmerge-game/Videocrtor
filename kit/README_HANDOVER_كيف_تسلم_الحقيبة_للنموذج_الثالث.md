# 📦 كيف تُسلَّم هذه الحقيبة للنموذج الثالث

1. أعطه ملفات الحقيبة الثمانية (`00` → `07`) كاملة (ارفعها أو الصقها).
2. **لا تعطه مستودعنا ولا توكننا.** عندما يطلب (بعد عرض الخطة) جهّز له: مستودع GitHub **جديد وفارغ** باسمه، وتوكن PAT **جديد** مقصور على ذلك المستودع (صلاحيات `repo` + `workflow`)، ومجلد Drive للتسليم. كود المحرك كاملاً موجود داخل الـ zip (`ENGINE_SOURCE/`) فلا يحتاج مستودعنا. ألغِ التوكن بعد انتهاء الاختبار.
3. الصق له المطالبة التالية حرفياً:

```markdown
ركز في كل حرف سأقوله لك الآن.
أرفقتُ لك (أو وضعتُ أمامك) **"حقيبة إنتاج شاملة (Production Kit)"** خاصة بنوع الفيديوهات الحصري بنا وبأدواتك وإعداداتك الدقيقة.

المطلوب منك الآن (كما نفعل عند فتح أي حقيبة جديدة):
1. **اقرأ جميع ملفات الحقيبة بالكامل (`00` إلى `07`)** وادرس بدقة:
   - الهوية البصرية والروح الخاصة بهذا النوع من الفيديوهات (`01_VISUAL_IDENTITY`).
   - الأدوات الخاصة والمعاملات والإعدادات الرقمية الدقيقة التي تمنع أي ضبابية وتحافظ على الحدة الأصلية 100% (`02_TOOLS_AND_EXACT_PARAMETERS`).
   - قواعد التحريك الكامل وبناء المشاهد (`03_MOTION_AND_SCENE_DYNAMICS`).
   - قواعد الصوت والمزامنة (`04_AUDIO_TIMING_AND_SYNC_SPEC`) والقوالب الجاهزة (`05_TEMPLATES`).
   - مواصفات اختبار فتح الحقيبة (`07_KIT_OPENING_TEST_SPEC`).
2. **اعرض عليّ الخطة أولاً وانتظر موافقتي (`Plan First -> Wait for Approval`):**
   - إياك أن تبدأ التنفيذ قبل أن تعرض عليّ خطة واضحة ومختصرة لصنع **"اختبار عملي كامل لهذا النوع من الفيديوهات"** يطبق كل قوانين الحقيبة وأدواتها بنسبة 100% (بموضوع جديد تماماً دون نسخ صور أو نصوص قديمة).
3. **بعد أن أعطيك الموافقة (`"ابدأ"`):**
   - قم بصنع فيديو الاختبار باستخدام أدواتك الموثقة في الحقيبة، مع الالتزام الصارم بـ **الحدة الكاملة (`Zero Blur`)** و**مدى التحريك الكامل**، وافحص النتيجة قبل تسليمها لي.
```

3b. **كيف تُسلّمه التوكن**: الصقه في المحادثة مباشرة عندما يطلبه (هذا هو المسار المعتمد في الحقيبة؛ لا يحتاج أي "تكامل GitHub" — يعمل بـ bash/curl/git). النموذج ملزم بحفظه في ملف فوراً دون طباعته وبعدم رفضه. يكفي أن تعطيه **اسم المستودع** (مثل `tastmap`)؛ هو يستخرج اسم حسابك من التوكن ويُنشئ المستودع بنفسه إن لم يكن موجوداً. ألغِ التوكن من إعدادات GitHub بعد انتهاء الاختبار.
4. انتظر خطته (يجب أن تطابق `07_KIT_OPENING_TEST_SPEC`)، ثم قل له **"ابدأ"**.
5. سيعرض عليك لقطات ثابتة + ناتج الفاحص `0 violations` قبل أن يطلب إذن الرندر النهائي؛ لا تعطِ إذن الرندر قبل أن ترى اللقطات.
6. استلم الفيديو على Drive مع `CREDITS_AND_LICENSES_KIT_TEST.md` والتقرير وفق القسم 5 من الملف `07`.
